업무 자동화실무 적용

통신사 환불 업무 자동화 시스템

환불 요청 메일과 관리자 사이트 처리 내역을 건별로 확인·대조해야 하던 업무를 하나의 흐름으로 통합했습니다.

2,323건약 6주간 통합 관리한 환불 요청
1개 장부메일·처리현황·송금 대기를 한곳에서 관리
업무 문제
다수의 환불 요청 메일을 읽고, 관리자 사이트에 등록하고, 송금·회신까지 건별로 추적해야 해 누락·중복 위험이 컸습니다.
수행 역할
요청 유형과 예외 처리 기준 정의, 화면·장부 구조 설계, 시험 실행으로 동작 확인 후 실무 적용
주요 구현
  • 환불 요청 메일 수신 및 내용 파싱
  • 요청 유형별 분류와 처리 현황 관리
  • 관리자 사이트 자동 등록 처리(Playwright)
  • 송금 대기·예외 건(계좌 미기재, 중복 환불 등) 관리
  • 처리 장부(SQLite)와 담당자 대시보드(Streamlit)
  • 안전장치: 시험 실행(DRY RUN) 모드, 메일 고유번호 기준 재처리 방지
확인된 성과
2026.07.29 ~ 09.10 약 6주간 환불 요청 2,323건을 하나의 장부로 통합 관리했고, 송금 완료·가입 제한 등 예외 유형별 처리 현황을 표준화했습니다.

결산·경영보고구현 완료

결산·경영보고 자동화

관리회계 결산자료와 더존 재무제표를 정제·통합해 KPI, Excel 보고서, 웹 대시보드를 한 번에 만드는 절차로 바꿨습니다.

1,490건3개년 원본·보고서 교차검증 전부 일치
3개년2024~2026 결산 데이터 통합
업무 문제
결산 원본 곳곳에 수식 오류와 연도별 구조 차이가 있어, 매월 수작업으로 보고 자료를 맞추고 숫자를 다시 확인해야 했습니다.
수행 역할
인건비·지급수수료 등 지표 정의 확정, 마감월·전망 구분 기준 결정, 원본 오류 유형 확인 및 보고서 구성 결정
주요 구현
  • 결산 원본 데이터 정제·통합(원본은 수정하지 않음)
  • KPI·경영지표 산출
  • Excel 경영보고서, PDF 보고서, 웹 대시보드(HTML·ECharts) 생성
  • 경영진 요약 보고서 구성, Power BI 보고서 파일 구성
  • 원본·모델·KPI·보고서 교차검증 — 불일치 시 보고서 생성 중단
  • 마감월만 바꾸고 실행하면 전체 재생성되는 월 운영 절차
확인된 성과
월간 결산 보고 절차를 표준화했고, 3개년(2024~2026) 데이터 교차검증 1,490건이 모두 일치함을 확인했습니다.

Power BI 보고서는 파일 구성과 일부 화면까지 확인한 단계입니다.

  • Python
  • Excel
  • Power BI
  • HTML/JavaScript
  • Claude Code
비용관리실무 적용

법인카드 및 비용관리 자동화

법인·사용자별로 흩어진 카드 명세서를 통합하고, 계정과목별 비용 분석과 경영진 보고서까지 한 번에 갱신되도록 했습니다.

원본 대조명세서 소계와 집계 총액 검증
실행 1회통합 → 분석 → 보고서 반영까지 갱신
업무 문제
카드사·법인마다 명세서 양식과 기준월이 달라, 매월 수작업으로 합치고 계정을 분류해 보고서를 만들어야 했습니다.
수행 역할
법인별 사용월 기준, 관리 계정 체계와 계정 변환 규칙 정의, 중복·취소 처리 기준 결정, 보고서 양식 확정
주요 구현
  • 법인별·사용자별 카드 사용내역 통합
  • 계정과목별 비용 분류(관리 계정 + 변환표)
  • 중복 거래 제외, 취소 건 순액 처리
  • 월별 비용 분석과 경영진 보고서·사용자별 내역 시트 구성
확인된 성과
카드 내역 취합부터 비용 분석·보고까지의 반복 절차를 표준화했고, 원본 명세서 총액과 보고 결과를 대조하는 검증 절차를 마련했습니다.

인사·근태실무 적용

근태 경영보고 자동화

출입기록 원본을 통합해 근무시간·근태 지표를 계산하고, 주간·월간 보고서를 자동으로 만들도록 했습니다.

0건원본 대조 104건 중 불일치
주간·월간Excel·웹 보고서 동시 생성
업무 문제
날짜별로 나뉜 출입기록을 매주 합치고, 연차·반차·재택을 반영해 근무시간을 계산하는 과정이 반복되었습니다.
수행 역할
근무예정일·실근무일·연차 가중치·점심시간 차감 등 집계 기준 정의, 보고서 항목 결정, 원본 데이터 이상 건 확인
주요 구현
  • 출입기록 데이터 통합(원본은 수정하지 않음)
  • 근무시간·지각·주 52시간 등 근태 지표 계산
  • 주간·월간 보고서 자동 생성(Excel, 웹)
  • 원본 데이터와 집계 결과 대조 검증
확인된 성과
근태보고서 생성 절차를 표준화했고, 원본 대조 검증(일수·총 근무시간 104건, 불일치 0건)으로 집계 정확성을 확인했습니다.

근태 점수·등급 산정은 의도적으로 넣지 않고 객관 지표만 보고합니다.
